# 리뷰어 A (방법론/통계) — 판정: Major revision

## 총평
연결 규칙 실증 비교와 한계 자백은 성실하나, 핵심 설계 결정들이 통계적 근거 없이 절차적 장치로 봉합됨. 명명가능성 검정의 신뢰도·일치도·오류율이 무측정. 모든 수치가 곧 폐기될 임베딩(라벨 12.3% 교정 전) 기준.

## Major issues
- **M1. τ_eff 정의 결함**: max cosine이 하필 병합 금지 위양성 쌍(0659/0892)에서 나옴 — 노이즈 하나가 "해상도"를 결정. ε 값 미명시. 위양성 제외 후 재정의 또는 "무병합 보장 임계값"으로 명칭 정정 요구.
- **M2. golden set n=12는 통계적으로 무의미**: 경계가 각각 단일 관측치로 결정. 표집이 cos≥0.88 근방에 집중되어 0.70~0.84 구간은 관측치 없음 → "과대병합 구간" 주장은 외삽. 0.70~0.84 층화 표집 수십~수백 쌍 인간 판정 추가 요구.
- **M3. 명명가능성 검정 무검증**: 공허한 상위어("AI 시스템 오작동 관련 리스크")도 통과 가능 — 추상도 상한 없음. 검수자 간 κ 측정 계획 없음. golden set 12쌍 소급 검증(승인 8 통과·금지 4 기각 재현)조차 미수행. false split 방향은 교정 불가한 비대칭 필터.
- **M4. 대안 탐색 부당하게 좁음**: Ward 누락(표준 후보), 제약 클러스터링 전용 방법(COP-KMeans 계열) 미검토, 그래프 기반(kNN+Leiden) 미검토. "average 21장 명명 불가" 논거는 complete 8장에도 부메랑 — 검정이 게이트면 average 배제 근거 아님.
- **M5. d=∞ 부작용 미분석**: cannot-link는 두 카드가 아니라 두 군집 계보 전체를 영구 분리 — 제3 카드의 배정 왜곡은 카드 수에 안 나타남. 제약 유/무 ARI 비교 요구. centroid/single에서 위반 잔존의 기술적 원인(∞의 산술 전파) 규명 요구.
- **M6. "검정 해상도 순 누적"은 중첩 문제 미해결**: C80 기각 군집의 C70 처리 미정의. C80 승인 카드 단위의 재클러스터링은 원 덴드로그램 절단이 아님 → ⊇ 증명 무효. C80 병합 카드의 σ 계산용 표현(재임베딩?) 미정의. 기각률만큼 C70 규모 상향 이탈 — 감축 목적과의 긴장 미정량.
- **M7. 곧 무효가 될 수치로 결론 도출**: golden set 유사도도 이동 → 운용대 자체가 이동 → §6 논증 전체가 조건부. 재생성 후 재산출 부록 또는 강건성 논증 요구.
- **M8. probability=max는 반보수적**: 부분 배반 사건이면 P(∪)≫max → 체계적 과소평가. severity max(보수)와 방향 불일치. "at least" 명시 또는 구간 [max, min(1,Σp)] 검토 요구.
- **M9. 재현 불가**: 모델 체크포인트·전처리·구현·tie 처리 규칙·golden set 전체 목록·선행 분석 인용 모두 결여.
