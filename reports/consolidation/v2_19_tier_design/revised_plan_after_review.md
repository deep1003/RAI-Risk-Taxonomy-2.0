## 확정된 설계 결정 (교수님 지시)

| 쟁점 | 결정 |
|---|---|

## 부모 L3 배정 절차 (확정 — 통합과 배정의 완전 분리)

원칙: **통합(Phase 1)과 L3 배정(Phase 2)은 별개 단계다.** 통합 카드는 새 명칭·정의를 가진 새 개체이므로, 구성원의 과거 소속(다수결 등)을 승계하지 않는다. 배정은 확정된 새 텍스트로부터 새로 계산한다.

**Phase 1 — 통합 (L3 완전 무시)**: τ 절단 → 명명가능성 검정 → 통합 명칭·정의 확정. C80·C70의 **모든 통합이 끝날 때까지** L3는 일절 고려하지도, 결정하지도 않는다. 통합 판정에 L3 정보를 입력으로 쓰지 않는다.

**Phase 2 — EM 배정 (통합 완료 후 일괄)**: 각 티어의 카드 세트가 확정된 뒤, 그 티어 전체를 대상으로 기존 릴리스 파이프라인과 동일한 **EM 기반 L3 배정**(v2.11~v2.17 remap 계열: L3 seed 초기화 → E-step 배정 → M-step centroid 갱신 → 수렴)을 실행한다. 통합 카드는 확정된 새 명칭·정의로 **재임베딩** 후 배정. margin·수렴 이력 기록, 저신뢰 배정(margin < 임계)은 hold 후 심의.

**계보 보존**: `merged_source_l4_ids`와 구성원의 구 L3를 `source_l3_ids`로 기록. Phase 2 배정 결과가 구 소속과 다르면 `reassigned_from` 명시. L1 교차 계보는 `cross_branch_lineage: true` 플래그.

→ 리뷰어 B M1 해소 + 기존 파이프라인과의 방법론적 일관성 확보. 부수 효과: Phase 2 재임베딩이 곧 재임베딩 방식(리뷰 지적 A-M4의 다섯 번째 대안)의 부분 실현이다.

## 리뷰 지적별 반영 사항

### 즉시 반영 (노트북에 구현)
- **A-M7 임베딩 미갱신**: 모든 수치는 Master 1,652장 재생성 임베딩으로 재산출. 기존 수치는 참고치로 강등
- **A-M1 τ_eff**: cannot-link 쌍 제외 후 max cosine으로 재정의, ε=0.001 명시. 명칭을 "무병합 보장 임계값"으로 정정
- **A-M4 Ward 추가**: linkage 비교표에 ward 포함 (L2 정규화 공간에서 유클리드-코사인 단조성 이용)
- **A-M5 제약 부작용**: 제약 유/무 두 실행의 카드 단위 diff + ARI 보고
- **A-M9 재현성**: 노트북에 모델 체크포인트 해시, 텍스트 포맷, scipy 버전, tie 규칙, golden set 12쌍 전체 목록 명기
- **B-M4 집계 왜곡**: severity/probability max 유지하되 (i) 구성원별 (s,p) 분포를 `member_metrics`로 보존, (ii) probability는 "at least" 명시, (iii) max-max가 어느 구성원과도 불일치하는 카드 수 보고
- **B-M6 참고문헌**: reference에 `source_l4_id` 태깅 보존. 상위 개념 직접 문헌 0건인 카드 비율 보고
- **B-M8 3H1R**: 합집합 대신 라벨별 구성원 비율 보존 (`three_h_one_r_profile`)
- **B-M5 정본성**: Master = 유일 정본. C80/C70은 파생 세트로 명시, 모든 파생 카드에 `master_source_ids` 필수 내장. manifest에 `derived_from: v2.19.0-master` 기록

### 명명가능성 검정 강화 (A-M3, B-M3)
- 사전 파일럿: golden set 12쌍 소급 적용 — 승인 8쌍 통과·금지 4쌍 기각 재현 확인 후 본 라운드 진행
- 2인 독립 판정, 불일치 해소 절차, 일치도(κ) 보고
- 부정 기준: 명칭이 소속 L3 라벨과 동어반복이면 기각, 나열식(and/및 2회 이상) 기각, 추상도 상한 = 기존 L3 라벨보다 구체적일 것
- 기각 시 구조화 기록: `rejection_rationale` 필드

### 중첩 구조 문제 (A-M6) — 절차 확정
- 덴드로그램은 1회 생성, 절단은 τ=0.80과 0.70 두 지점에서 수행 (순수 절단, 단조성으로 ⊇ 보장)
- 명명 검정 기각은 **두 해상도에 동일하게 전파**: C80에서 기각된 병합은 C70에서도 해당 부분을 분리 유지 (기각 = 해당 내부 노드를 트리에서 무효화). 이렇게 하면 재클러스터링 없이 ⊇ 성질 유지
- 기각률만큼 최종 카드 수가 목표(1,458/844)를 상회함을 수용 — 수치는 결과값

### 후속 라운드로 이관 (이번 실행에 포함하지 않음)
- A-M2 golden set 확장 (0.70~0.84 층화 표집 인간 판정) — 명명 검정 기각률 데이터가 쌓이면 그것이 사실상 확장 golden set이 됨
- A-M4 그래프 기반(Leiden) 대안 비교
- 재임베딩 방식 소표본 검증 (군집 50개)
- B-M5 버전 동기화 정책, source_crosswalk 승계 설계

## 실행 순서 (교수님 승인 후)

1. 노트북 작성 (셀 단위, 교수님 눈으로 확인하며 실행)
2. 노트북 코드 리뷰 (2인)
3. 승인 후 실행: 임베딩 재생성 → 덴드로그램 → 절단(0.80/0.70) → golden set 파일럿 → 명명 라운드 완주(Phase 1, L3 무관) → 티어별 재임베딩 + EM 배정 일괄(Phase 2) → 세트 생성 → 검증
