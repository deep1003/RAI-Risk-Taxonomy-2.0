## 1. 검토의 전제: 리스크 성립 기준

본 검토는 모든 L4 항목이 다음 4요소를 갖춘 **리스크 진술문**이어야 한다는 기준을 적용했다.

1. **원인(AI 관여)**: 피해가 AI 시스템의 행동·산출물·실패 또는 AI가 가능하게 한 인간 행위에 인과적으로 귀속될 것
2. **경로(발생 메커니즘)**: 원인에서 피해로 이어지는 경로가 서술될 것
3. **결과(피해)**: 신체적·심리적·경제적·권리적·사회적·환경적 손상이 특정될 것
4. **불확실성**: 실현되지 않은 가능성일 것

이 기준으로 성립하지 않는 유형은 다음과 같이 판정했다: **역량 기술**(능력의 존재만 서술), **도메인 분류**(피해가 발생할 무대만 서술), **상태·요인 기술**(원인 측 조건만 서술), **정책 범주**(규범 위반이나 피해 주체 불명).

## 2. 작성 규칙 (수정안에 일괄 적용)

| # | 규칙 | 근거 |
|---|---|---|
| R1 | **계층 수준 유지**: 수정 시 L3와 같은 상위 추상 수준으로 일반화하지 않고 L4의 구체성(특정 메커니즘·맥락)을 유지한다. L4 수준으로 구체화가 불가능한 항목은 수정하지 않고 비고란에 폐기 권고를 기술한다. | 계층 간 중복 방지(검토자 지시) |
| R2 | **문장 톤·분량**: 정의문은 L3 마스터와 동일하게 1문장, 국문은 "~하는 리스크."로 종결, 영문은 "The risk that …" 구조를 따른다. 초과 시 비고에 축약 필요를 플래그한다. | L3 마스터 컨벤션과의 일관성 |
| R3 | **명칭 접미어 제거**: 명칭은 분류 라벨(명사구)이므로 "리스크/위험" 접미어를 달지 않는다(예: "유해 행동 재구성 공격 리스크" → "유해 행동 재구성 공격"). 영문 "Risk of X"도 "X"로 정규화한다. 리스크 진술은 정의문이 담당한다. | L3 마스터 국문 명칭 컨벤션(폭력, 자해, 과도한 거절 등) |
| R4 | **추적성**: 모든 행에 `원본추적ID` 컬럼을 두어 원본 ID(RAI4-xxxx)를 기재한다. 병합 행은 원본 ID 전체 목록(`\|` 구분)을, 원본 ID가 없는 신규 유입 행(92건)은 원본 CSV 행 추적값을 `KTSPACE-{도메인}:{source_row_id}` 형식으로 기재한다. | 원본 리스크로의 소급 추적(검토자 지시) |
| R5 | **재정의의 준거**: 재정의된 정의는 AI 기본법(제31조 투명성, 제32조 안전성, 제34조 고영향 AI 사업자 책무), TTA 「신뢰할 수 있는 AI 개발안내서」 요구사항, OECD AI 원칙, NIST AI RMF의 리스크 개념·용어로 기술하고 `근거` 컬럼에 명기한다. | 검토자 지시 |

## 3. 검토 절차 (수행 순서)

### 3.1 원본 무결성 확인
업로드본 3개 파일과 로컬 원본(`02_working/review_csv/`)의 SHA-256 해시 일치를 확인했다(3/3 일치). 검토 대상이 진본임을 보장하기 위한 절차다.

### 3.2 구조 검사 (자동, 826행 전수)
다음 항목을 스크립트로 검사했다.

- 한/영 명칭·정의 공란: **0건**
- 영문 정의 "The risk that…" 형식 위반: **0건**
- 국문 정의 "~리스크/위험" 종결 위반: **0건**
- 명칭 중복: **0건**
- 국문 표기 훼손(중점 뒤 공백 "물리적· 재정적", 어절 분리 "커 버리지", "오 분류" 등): **다수 검출** — 원문(`original_description_ko`)에는 없는 훼손이 재작성 과정에서 유입된 것을 428건에서 확인

### 3.3 의미 검사 (수동, 전수 열람)
826행의 명칭·정의를 전부 열람하여 1절의 4요소 기준으로 판정했다. 원본(KTSPACE) 단계에서 지적했던 결함 28건 중 의인화 표현유형(10건)·모델 자산(6건) 항목은 이번 재작성에서 피해 절이 추가되어 이미 교정되었음을 확인했고, 다음 9건이 미해결로 남아 재정의 대상이 되었다.

| 원본추적ID | 문제 유형 | 조치 |
|---|---|---|

| RAI4-1159 | 역량 기술(정치 영향 전략) | 재정의: 오용 주체·여론 왜곡 피해 명시 |

| RAI4-1157 | 역량 기술(공격적 사이버) | 재정의: 사이버 공격 악용·시스템 침해 명시 |
| RAI4-1413 | 상태 기술(연구인력 다양성) | 재정의: 편향 산출이라는 결과 명시 |

### 3.4 국문 표기 복원 (3단계)
재작성 과정에서 유입된 국문 띄어쓰기 훼손을 다음 순서로 복원했다. 임의 수정을 피하기 위해 **반드시 검증된 원문과의 대조**를 우선했다.

1. **원문 대조 복원**: 무공백 문자열이 일치하는 경우, 검증된 클린 텍스트로 치환 — 명칭은 최종 릴리스본(`03_final_release`) 기준 761건, 정의는 `original_description_ko` 기준 429건 + 릴리스본 기준 54건
2. **말뭉치 대조 복원**: 1단계로 복원되지 않은 행은, 클린 말뭉치(릴리스본 + KTSPACE 원본 + L3 마스터의 국문 전체)에서 "공백 제거형은 존재하고 공백 유지형은 존재하지 않는" 어절 분리만 제거(95행). 말뭉치에 근거 없는 공백은 수정하지 않음
3. **수동 교정**: 말뭉치로 판정 불가한 잔여 패턴을 개별 확인 후 교정 — "기반적 대·차별적"→"기반 적대·차별적"(14건), "오 류"→"오류" 등. 최종 잔여 훼손 0건 확인

## 4. 산출 파일 스키마

원본 컬럼(1~8열)은 그대로 보존하고, 수정 제안은 별도 컬럼에만 기재하여 원본 대비 diff가 가능하도록 했다.

| 컬럼 | 내용 |
|---|---|
| `원본추적ID` | 규칙 R4의 추적 식별자 (RAI4 단일 720 / 병합 목록 14 / KTSPACE 추적값 92) |
| `source_row_id`, `source_l4_id`, `target_domain` | 원본 파일의 식별 정보(보존) |
| `title_ko/en`, `description_ko/en` | 원본 명칭·정의(무수정 보존) |
| `대안_리스크명칭_ko/en` | 수정 제안 명칭(접미어 제거 규칙 R3 적용) |
| `대안_정의_ko/en` | 수정 제안 정의(규칙 R1·R2·R5 적용) |
| `변경유형` | `REDEFINITION`(8) / `DROP_권고`(1) / `SPACING_FIX`(713) / `UNCHANGED`(104) |
| `근거(법령·가이드라인)` | 재정의의 준거 규범(R5) 또는 "표기 교정" |
| `비고` | 재정의 사유, 폐기 권고 사유, L3 분량 초과 플래그 등 |

## 5. 한계 및 후속 검토 필요 사항

- 재정의 9건과 폐기 권고 1건은 AI의 제안이며, 원저자의 의도(예: dangerous capability를 독립 층위로 유지할지)에 따라 다른 결정이 가능하다.
- `비고`의 "분량 초과" 플래그가 남은 행들은 L3 톤(1문장)으로의 축약이 별도 작업으로 필요하다.
- 말뭉치 대조 복원(3.4의 2단계)은 보수적으로 설계했으나, 클린 말뭉치 자체에 없는 신조어·복합어는 복원되지 않았을 수 있으므로 국문 감수 1회를 권장한다.
- 근거 규범 표기는 조항 수준(AI 기본법 §31·§32·§34)까지만 매핑했으며, 시행령·고시 수준의 세부 매핑은 수행하지 않았다.
