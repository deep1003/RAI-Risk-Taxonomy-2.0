## 1. 확정된 사실 관계

1. **원칙.** L4 카드의 식별은 ID가 아니라 **명칭·정의의 의미**로 한다. 통합·재번호(compaction)로 ID는 스냅샷마다 달라지며, ID 직접 적용은 오적용을 낳는다.
2. **사용자 지시 통합 10건은 전부 적용 완료.** 지시 ID는 통합 이전 스냅샷 기준이었고, Codex가 `user_directed_operations.csv`(지시 ID→당시 ID→대표 ID)와 `Human_Review_Round2_Decision_Ledger.csv`(`L4_ID_Before`)에 매핑을 기록한 뒤 MERGE를 반영했다. 확정 대조표는 본 폴더 `Semantic_Merge_ID_Resolution.csv` 참조.
3. **권고 문안 6건도 반영 완료.** STATE_003, CULT_023, COPY_008, PRIV_021, SELF_007, VIOL_003의 현행 명칭·정의가 사용자 권고 문안과 일치함을 문자 대조로 확인했다.
4. **원본 보존.** 8/28 수신 KTSPACE 검수 CSV 4개(L3 46 + L4 808행, 검토의견 251행)는 수신 이후 무변경(SHA-256·git·mtime 일치), read-only manifest로 고정.
5. **분리 유지 원칙(하드 가드, 지속 적용).** 정치적 견해 / 인종·민족 / 장애 / 성별·성정체성·성적 지향 기반 표상은 상호 통합 금지(동일 계열 내부 통합은 허용). 자살 준비(SELF_007)·실행(SELF_010) 분리 유지. 폭력 통합 정의에 자해·일반 불법행위 문구 불포함.
6. **불변 규칙.** EM/Hybrid EM 재실행 금지, 신규 L3 생성 금지, L3 마스터 해시 고정, 기존 승인 문안 무단 변경 금지, 통합 시 `source_row_id`·`facet`·`act-type` 합집합 보존, 흡수 ID 재사용 금지.

## 2. 잔여 작업 (3단계)

### 2-1단계. 기적용 10건 검증 (데이터 무변경)
- 각 통합 건에 대해: ①대표 카드에 흡수 카드의 `source_row_id`·`facet`·`act-type` 합집합 보존 여부 ②흡수 카드 명칭의 잔존(중복 부활) 여부 ③권고 문안과 현행 문안의 문자 단위 일치 ④분리 유지 원칙 준수(성별·인종민족·장애·정치 교차 통합 0건) 검사.
- 산출물: `Merge_Verification_Report.csv` (건별 PASS/FAIL·근거).
- Codex 자체검증 FAIL 5항목(정확 중복·계보 유실·한/영 문안 불일치·최종 QA 불일치)과 교차 대조하여, 본 10건이 FAIL 원인에 포함되는지 여부를 명시한다.

### 2-2단계. 한국어 엄밀성 교정 패스 (전 카드)
- 규칙:
  - 표준 띄어쓰기 — "월드 모델", "재산 정보", "준비 행위" 등 일반 합성어는 띄어 쓴다.
  - 법정 용어는 법전 표기 유지 — "2차적저작물"(저작권법 제5조), "정보주체", "개인정보자기결정권", "저작재산권자".
  - 문장 구조 — 1문장, 명사형 종결("~하는 리스크."), 마침표 1개, 가운뎃점(·) 나열 방식 통일.
  - 문체 — 이중 피동·번역투·"~에 대한" 남용 제거, 한·영 정의 의미 동치 유지.
- 방식: 자동 린트로 후보 추출 → 수기 확정 → 수정 전후 대조표(`Korean_Copyedit_Semantic.csv`) 산출. **기존 승인 문안(한 519·영 320·QA 186건 명세)은 잠금**하고 신규 위반만 수정.
- 적용 경로: Codex 복구 원장에 교정 연산으로 등재 후 파이프라인 적용(수기 CSV 편집 금지).
