# 전 L4 레퍼런스 부착 작업계획서

수립 2026-08-30 · 대상: 최종 릴리스 629장(커밋 0e33a4c) · 기보유 11장 → **신규 대상 618장**

## 원칙 (사용자 지시)
1. 카드당 최소 1개의 **가장 신뢰성 있는 논문**. 가능하면 해당 리스크를 **최초로 명명·정의한 문헌**, 또는 신뢰성 있는 저널·주요 학회(NeurIPS/ICML/ICLR/ACL/FAccT/CCS/S&P 등)·표준기관(NIST/ISO/EU) 문서.
2. **링크는 논문이 바로 열리는 살아있는 링크**여야 한다(arXiv abs, DOI, 기관 공식 페이지).
3. **출처가 불확실하거나 링크가 열리지 않으면 달지 않는다.** 미부착이 오부착보다 낫다.
4. 이 과정에서 제목·정의가 문헌과 불일치하거나 수정이 필요하면 **보수적으로 최소한만** 다듬는다.
5. 전 결과는 전문 에이전트 2인의 검수를 거친다. 거의 완벽할 때만 commit & push.

## 인용 조작 방지 설계 (핵심)
LLM 인용의 지배적 실패는 "실재하는 DOI + 조작된 제목"이다. 따라서 제안 단계와 검수 단계 모두에서 **식별자가 실제로 해석되는지 + 해석된 제목이 주장한 제목과 일치하는지**를 확인한다.
- arXiv: `http://export.arxiv.org/api/query?id_list={ID}` (경량 XML, 제목 확인)
- DOI: `https://api.crossref.org/works/{DOI}/transform/text/x-bibliography` (단문 서지 반환)
- 표준·기관 문서: 공식 페이지 직접 확인(csrc.nist.gov 등)
검증 실패·제목 불일치 시 해당 제안은 폐기한다.

## 단계
1. **입력 구축(기계)**: 618장을 L3 단위로 묶어 배치 파일 6개 생성(카드 ID, 한/영 명칭, 영문 정의, 소속 L3 맥락).
2. **제안(에이전트 6인 병렬)**: 배치별로 카드마다 최대 2개 후보를 제시하되, **각 링크를 스스로 검증하고 해석된 제목을 함께 보고**. 확신이 없으면 공란(coverage보다 정확성 우선). 문안 교정이 필요하면 별도 열에 최소 수정안 제시.
3. **기계 검증(총괄)**: 산출물 병합 후 형식·중복·ID 유효성 검사, 식별자 정규화, 무작위 표본 직접 재확인.
4. **검수(에이전트 2인 독립)**: A — 링크 생존·제목 일치·서지 정확성. B — 리스크-문헌 **주제 적합성**과 "최초 명명/권위" 기준 충족, 과잉 인용·부적합 인용 색출. 합의 불가·부적합 판정 건은 **삭제**(보수 원칙).
5. **적용**: 검수 통과분만 References에 기재(CSV 전체 컬럼본 + cards.json + 웹 표시), 문안 교정은 승인된 최소 수정만. 게이트 재검증 후 commit & push.
