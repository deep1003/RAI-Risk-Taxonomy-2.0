# 휴먼검수 의도 반영 최종 검증 작업계획서 (Fidelity-2)

수립 2026-08-30 · 대상: 최종 릴리스 629장(커밋 0e33a4c) · 원천: KTSPACE 검수 CSV 3종의 휴먼검토의견 251건

## 배경
1차 충실성 검증(AC-03 시점, 720장)은 반영 246/부분 3/미반영 2였다. 이후 AC-05~AC-08(빈 L3 보충, 재조정, 전체 MECE 큐레이션[흡수 64·이관 18·제거 2], 복합 18장 분해)로 카드가 추가로 소멸·이동·분해되어, 의견이 반영됐던 카드의 의미가 대표 카드에 보존되지 않았을 가능성이 새로 발생했다. 원천행→최종 카드 전체 사슬을 재검증한다.

## 검증 사슬
원천 CSV 행(의견 원문) → 지시 등록부(HR2-####, source_row_id) → 현행 처분 원장(AC-10 시점 Output_L4_IDs) → 최종 카드 문안(629장). 의견 원문의 등록부 verbatim 일치는 1차에서 251/251 확인, 재확인 포함.

## 단계
1. 입력 구축(기계): 251건 × [의견 원문 / 기준선 카드 / 현행 처분 / 최종 귀착 카드 명칭+정의 전문 / 1차 판정] 추적표.
2. 독립 검수(2인): A 분류학 관점(판정+반영결과 요약), B 평가·정책 관점(판정+원인코드 LOST_IN_MERGE/LOST_IN_DECOMPOSE/IGNORED/MISREAD/CONFLICT/PARTIAL_SCOPE+분석). 상호 열람 금지, 전수.
3. 제3자 재검토(총괄): 251행 라인바이라인 — 두 판정과 최종 문안 증거를 행별 대조해 최종 판정 확정, 소실 시 AC 단계 특정. 판정 기준은 의견의 취지(문구 아님).
4. 결과서: 판정 분포, 비반영 전수 목록(원문·소실 단계·원인), 1차 대비 변화, 권고 시정. 데이터 수정 없음.
